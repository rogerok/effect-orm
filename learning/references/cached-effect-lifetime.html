Один кеш —
один общий результат.

Урок 0010 · Карта обучения

Словарь

Мемоизация (memoization)
Повторное использование сохранённого результата вместо повторного вычисления.
Внешний эффект
Результат вызова Effect.cached(work). Каждое его исполнение создаёт отдельный кешированный эффект.
Внутренний эффект
Полученный кешированный эффект. Его первый запуск вычисляет результат, следующие используют сохранённый.
Время жизни кеша
Для кеша без TTL результат доступен через созданный внутренний эффект; новое исполнение внешнего эффекта не обращается к прежнему кешу.

Три контрольных случая

  • Создать кеш, но не запускать внутренний эффект: исходное вычисление ещё не выполнялось.
  • Один кешированный эффект запустить дважды: исходное успешное вычисление выполнится один раз.
  • Создать два кешированных эффекта и запустить каждый: исходное успешное вычисление выполнится дважды.

Граница ORM

Сохраняется пара { sql, params }, а не результат executeRaw. Содержимое IR включает значения литералов; диалект также влияет на результат. Диалект можно закрепить за экземпляром кеша либо учитывать при поиске записи.

Effect.cached сам не ищет запросы по ключам. И одинаковый числовой хеш ещё не доказывает равенство запросов. Устройство этого поиска — следующий шаг, не часть освоенного механизма.

Источник: Effect.cached, 4.0.0-rc.108 и реализация. Сценарии выше относятся к последовательному успешному вычислению; ошибки и прерывание здесь не разбираются.
