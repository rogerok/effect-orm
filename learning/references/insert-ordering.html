Словарь

Ориентированный граф (directed graph)
Вершины и рёбра с направлением. У нас вершина — таблица.
Ребро from → to
from вставляется раньше to. Родитель → потомок.
DAG (directed acyclic graph)
Ориентированный граф без циклов. Только для него существует порядок.
Топологическая сортировка (topological sort)
Список вершин, где каждое ребро идёт слева направо. Правильных списков может быть несколько.
Входящая степень (in-degree)
Число рёбер, которые указывают в вершину.

Каждую таблицу из tables заранее кладём в обе Map — иначе таблица без рёбер потеряется.

Алгоритм Кана

  1. Посчитать in-degree каждой таблицы.
  2. Очередь ← все таблицы с in-degree 0.
  3. Взять таблицу из начала очереди, добавить в результат.
  4. Для каждой таблицы из её adjacency: in-degree − 1; стало 0 → в конец очереди.
  5. Повторять 3–4, пока очередь не пуста.
  6. Результат короче tables → цикл. Остаток = таблицы цикла и все, кто от них зависит.

Как тестировать

  • Не сравнивать с одним точным списком. Проверять: все таблицы на месте + indexOf(from) < indexOf(to) для каждого ребра.
  • Ошибку подсчёта in-degree ловит граф, где у таблицы два родителя, и один освобождается позже другого (sections → categories → posts, users → posts).
