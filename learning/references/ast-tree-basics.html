AST — дерево обычных объектов

Минимальный словарь для чтения текущего Predicate без compiler theory.

Четыре термина

AST
Абстрактное синтаксическое дерево (Abstract Syntax Tree): вложенные объекты, которые описывают запрос, но не выполняют его.
Узел
Один объект дерева. Например, { _tag: "Not", pred: ... }.
_tag
Поле-дискриминатор: сообщает, какой это вариант объекта и какие остальные поля у него есть.
Преобразование
Функция получает дерево и возвращает другое дерево. Исходные объекты не изменяются.

Как читать вложенность

{
  _tag: "Not",              // внешний узел
  pred: {
    _tag: "Not",            // его ребёнок
    pred: p                  // ребёнок внутреннего Not
  }
}

Запись выше читается изнутри наружу: есть условие p, его отрицали, затем результат отрицали ещё раз. Два отрицания можно убрать, поэтому итог — p.

Рекурсия в одной фразе

Если поле узла снова содержит Predicate, функция обрабатывает это поле вызовом самой себя. Это не специальная backend-механика: тот же приём используется при обходе DOM, дерева комментариев или вложенного меню.

Чистота

  • Не присваивать новое значение полям входного объекта.
  • Не изменять входные массивы через push, splice или sort.
  • Можно вернуть уже существующий вложенный узел p: его переиспользование не является мутацией.
  • Когда дети изменились, родитель собирается новым объектом.

Один вопрос при чтении каждой ветки

Какие поля этого узла содержат другие узлы? Для Not это pred; для And и Or — массив preds; для Gt вложенных предикатов нет.
