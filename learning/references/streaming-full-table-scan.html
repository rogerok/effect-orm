E2.7 · справочник

Потоковый full table scan

Короткая карта типов, ответственности и проверок. Открывай после первой самостоятельной попытки.

Урок 0012 · Карта обучения

Цепочка данных

Select<R>
  → compile(statement, driver.dialect)
  → driver.executeStream(sql, params, chunkSize)
  → Stream<R, DriverError, Driver>
  → runFold({ count, sum }, reducer)
  → Effect<{ count, sum }, DriverError, Driver>

Инвариант памяти

Живой объём данных должен зависеть от размера текущего chunk и аккумулятора, а не от общего числа строк:

live rows ≈ current chunk + driver buffers
accumulator size = constant

не должно быть:
executeRaw(...).rows
Stream.runCollect
accumulator.rows.push(row)

Роли API

Stream.unwrap
Получить зависимость или выполнить подготовительный Effect, который создаёт внутренний Stream.
fromIterableEffect
Преобразовать effectful Iterable в Stream. Экономия памяти зависит от самого Iterable: ленивый iterator подходит, заранее созданный массив — нет.
Stream.paginate
По запросу consumer выполнить следующий шаг и вернуть [rows, nextState]; Option.none() завершает поток.
Stream.runFold
Свести элементы в один аккумулятор. Ограниченная память сохраняется только при аккумуляторе фиксированного размера.

Границы проекта

  • Публичный typed helper принимает только Select<R>; UPDATE и DELETE не являются full table scan.
  • SQLite producer должен опираться на stmt.iterate(), не на stmt.all().
  • PGlite producer должен извлекать порции cursor/FETCH и закрывать cursor/transaction при любом завершении.
  • Текущий libsql driver содержит пустую заглушку executeStream; упражнение курса описывает SQLite и PGlite, поэтому эту отдельную интеграцию не считать доказанной.

Acceptance matrix

СвойствоНаблюдение
Тип строкиЭлемент потока выводится как R из Select<R>.
Корректностьcount равен числу вставленных строк; sum равна заранее вычисленной сумме.
ЛенивостьДо запуска terminal operation запрос и получение строк не выполняются.
ПамятьPeak не растёт пропорционально миллиону row-объектов; runCollect служит контрпримером.
ОчисткаProducer освобождает cursor/transaction при success, failure и interruption.

Память Node.js

  • heapUsed — занятая память V8 heap.
  • external — память C++-объектов, связанных с JavaScript; важна для native SQLite.
  • rss — резидентная память всего процесса, включая JS, native-объекты и код.
  • Snapshot до/после показывает удержанные объекты, но не гарантирует обнаружение краткого peak.
