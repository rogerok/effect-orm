## Completion criteria for the current task

- Builder хранит runtime-карту `alias → TableDef`, заполняемую в `selectFrom`, `innerJoin` и `leftJoin`.
- `select()` строит соответствие «ключ результата → декодер» только для записей проекции с `_tag: 'Column'`
  и только при наличии `_codec` у найденной `ColumnDef`.
- Диалект берётся в момент исполнения, а не при сборке запроса.
- `toIR()` возвращает `SelectIR` без новых полей; функции и `TableDef` в IR не попадают.
- Значение `null` в `decode` не передаётся.
- Декодирование применяется во всех трёх terminals `ExecutableQuery`.
- Приведение типа поставлено на минимальное значение, инвариант назван словами.
- Проверка: `pnpm check-types` — код `0`; сценарий SQLite даёт `enabled: true`/`false` при `typeof === 'boolean'`,
  `id` остаётся `number`; колонка без `_codec` и запись `b.lit(...)` в проекции не меняются и не вызывают ошибку.
- Вне шага: `selectAll()`, кодирование параметров, `returning` в write-builders, обёртка ошибки в `CodecError`.
