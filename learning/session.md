## Completion criteria for the current task

- `deleteFrom(table)` создаёт исполняемый запрос без этапа `set` или `values`.
- `where` допускает только колонки указанной таблицы, повторные условия объединяются через `And`.
- Без WHERE запрос удаляет все строки; такое поведение обозначено явно.
- `returning` возвращает выбранные поля удалённых строк и согласует их с типом результата.
- Без `returning` результат содержит `affectedRows`; исходный запрос не изменяется при построении производного.
- Временный сценарий на SQLite подтверждает удаление выбранной строки и сохранение остальных.
- `pnpm check-types` проходит. Постоянные тесты UPDATE и DELETE выполняются одним следующим этапом.
