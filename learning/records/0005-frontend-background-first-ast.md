# Исходная точка — фронтенд без опыта работы с компиляторами и ORM

Пользователь сообщил, что раньше писал только фронтенд и впервые сталкивается с ORM, оптимизатором AST и связанными концепциями backend-разработки. Это уточнение отменяет прежний вывод о готовности сразу воспроизводить весь пайплайн: следующие уроки должны вводить по одному понятию через знакомые JavaScript, DOM и преобразование объектов, не предполагая знания терминологии компиляторов, функционального программирования или SQL-семантики.

**Evidence:** прямая самооценка пользователя перед началом E2.3.
