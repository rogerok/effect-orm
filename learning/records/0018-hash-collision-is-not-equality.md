# Совпадение хешей не разрешает переиспользование Compiled

Пользователь верно предсказал, что при коллизии схема `Map<number, memo>`, возвращающая запись сразу по совпадению хеша, отдаст результат другого запроса. Это подтверждает понимание последствия коллизии; конкретный механизм проверки равенства и выбор коллекции ещё не проверены.

**Evidence:** ответ «результат другого запроса при коллизии» на пример разных литералов с условно одинаковым хешем 42. Следующий шаг — различить ссылочное равенство ключей JavaScript Map и структурное равенство ключей Effect HashMap в установленной версии.
