# SQL OR не возвращает один из операндов

Пользователь после контрпримера отличил JavaScript `||` от логического `OR` в AST и правильно вывел `Or(Boolean(false), p, Boolean(false)) → p`: `false` является нейтральным элементом `OR`, поэтому оба константных ребёнка удаляются. Это позволяет дальше разбирать оптимизацию `Or` через логические законы, а не через JavaScript truthy/falsy.

**Evidence:** пользователь самостоятельно ответил, что после удаления двух `Boolean(false)` остаётся `p`.
