# Вложенный Predicate требует отдельного сужения типа

Пользователь объяснил, что проверка внешнего `_tag === "Not"` гарантирует форму только корневого узла, а для доступа к `input.pred.pred` нужно отдельно подтвердить `_tag` дочернего предиката. Следующие ветки можно строить через тот же вопрос: какой узел уже сужен и какие дочерние поля после этого гарантированы.

**Подтверждение:** пользователь самостоятельно сформулировал отсутствие гарантии для вложенного `Predicate` без второй проверки.
