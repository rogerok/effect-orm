# SQLite stream свёрнут без материализации результата

Пользователь собрал сквозной сценарий `Select<R> → compiler → SQLite stmt.iterate() → Stream → runFold`: три строки `10, 20, 30` дали точный результат `{ count: 3, sum: 60 }`. Узкий Vitest прошёл, LSP-диагностика чистая; пользователь также восстановил модель multi-row `VALUES` как набора row tuples, где ширина каждой строки совпадает со списком target columns.

**Implications:** функциональный путь E2.7 доказан на малом наборе. Следующая отдельная задача — построить миллион строк без предварительного массива JavaScript и измерить peak/retained memory, не смешивая стоимость подготовки данных со scan.
