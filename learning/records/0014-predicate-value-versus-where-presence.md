# Логическое значение предиката отделено от наличия WHERE

Пользователь правильно вывел, что `where: And(p, Boolean(true))` после оптимизации становится `where: p`: `optimizePredicate` упрощает логическое выражение, а `optimizeSelect` удаляет секцию `where` только когда весь итоговый предикат равен `Boolean(true)`. Это различие позволяет не путать значение узла `Predicate` со структурным отсутствием optional-поля запроса.

**Evidence:** пользователь самостоятельно предсказал итоговый `where: p` после объяснения двух уровней оптимизации.
