# Миссия перешла к E2.7: потоковый full table scan

Пользователь явно выбрал следующей целью упражнение E2.7: типизированный `Stream` для full table scan, свёртку миллиона строк без материализации результата и проверку потребления памяти. Это меняет ближайший маршрут с `Effect.Request` на границы producer → typed adapter → consumer; понимание потоковой модели пока не подтверждено и сначала диагностируется в уроке 0012.

**Implications:** backend-код и эксперимент пишет пользователь; преподаватель не считает сам тип `Stream` доказательством ограниченной памяти и отдельно проверяет ленивость источника, размер аккумулятора, очистку ресурса и корректность memory measurement.
