# Typed stream сохраняет ленивую границу исполнения

Пользователь самостоятельно исправил адаптер `Select<R> → Stream<R, DriverError, Driver>`: сервис `Driver` извлекается внутри эффекта, поток драйвера возвращается без `yield*`, а raw rows явно проходят assertion boundary к `R`. Проверка типов чистая; smoke test подтвердил, что до terminal operation драйвер не вызывается, после `runFold` вызывается один раз, получает `chunkSize = 17`, а две строки сворачиваются в `{ count: 2, sum: 5 }`.

**Implications:** можно переходить от fake Driver к маленькому сквозному сценарию на SQLite и затем отдельно проектировать миллионную загрузку и измерение peak memory.
