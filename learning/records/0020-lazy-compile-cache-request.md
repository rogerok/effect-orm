# Обработка IR отложена до запуска эффекта

Пользователь перенёс Effect.gen внутрь compileCache(ir), оставив общую коллекцию в замыкании фабрики. Теперь создание эффекта запроса не запускает компиляцию. Это устраняет прежнее смешение эффекта создания фабрики и эффекта обработки конкретного IR.

**Evidence:** изолированное исполнение текущей фабрики с настоящим compile: после вызова compileCache(ir) компиляций 0, после первого Effect.runSync — 1, после исполнения обращения с новым структурно равным IR — по-прежнему 1. Возвращённый результат переиспользован. Backend-код преподаватель не менял.

Коллекция пока хранит Compiled. work и makeCached создаются, но не используются; в генератор добавлен лишний placeholder через Effect.void. Следующий шаг — получить memo и исполнить его вместо прямой компиляции, затем сохранять сам memo.
