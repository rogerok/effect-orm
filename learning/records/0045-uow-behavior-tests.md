# Очередь эффектов проверена через состояние БД

Пользователь реализовал очередь эффектов записи и написал тесты на SQLite: запись отсутствует до `commit`, появляется после успеха, а ошибка второй отдельной вставки откатывает первую. После подсказки пользователь дополнил проверку `UniqueViolationError` чтением пустой таблицы; два теста и `pnpm check-types` прошли.

Это подтверждает практическую работу с тестами отложенной записи и отката с помощью наставника, но не самостоятельное понимание различия транзакции и Unit of Work: пользователь прямо попросил разобрать это различие. Для продолжения использовать [урок 0014](../lessons/0014-transactions-and-unit-of-work.html), затем попросить один прогноз состояния без готового ответа.
