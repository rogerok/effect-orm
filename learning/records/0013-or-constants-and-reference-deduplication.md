# Or различает нейтральный false и поглощающий true

Пользователь реализовал рекурсивную оптимизацию `Or`: повторяющиеся исходные ссылки устраняются через `Set`,
`Boolean(false)` пропускается, `Boolean(true)` завершает весь `Or`, а результат нормализуется по числу детей. Он также
разделил JavaScript `||`, constant folding дочернего `Eq` и логические законы SQL-предикатов.

**Evidence:** все 11 тестов `../../src/compiler/optimize.test.ts` и `pnpm check-types` прошли, включая `Or()`, оба
Boolean-случая и `Or(p, p)`.
