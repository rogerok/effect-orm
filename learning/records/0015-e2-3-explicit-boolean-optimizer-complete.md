# E2.3 завершён через явный Boolean-предикат

Пользователь самостоятельно собрал полный проход `Predicate → optimizePredicate → optimizeSelect → compile`: добавил явные логические константы, рекурсивные правила `And` и `Or`, reference-дедупликацию, constant folding `Eq`, удаление верхнеуровневого истинного `where` и сохранение ложного. Он подтвердил отсутствие мутации и различил значение предиката от наличия секции `WHERE`.

**Evidence:** 22 связанных теста компилятора, pretty-printer и optimizer прошли; `pnpm check-types` прошёл. Реализация намеренно расходится с исходным acceptance-тестом курса, ожидающим `null`, поэтому контракт Boolean должен быть согласован с ментором.
